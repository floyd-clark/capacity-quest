# Complexity Lab problem map

All numbers, costs, scope boundaries and dates are synthetic teaching assumptions. Reopening tests are modeled outcomes, not real qualification results.

| Set | Domain / source cases | Governing constraint | So what / bounded scope |
|---|---|---|---|
| CX-01 — Bulk flow is green. Four trays are not. | Cooling; SI-001-4, SI-007-2 | Q(kW)=0.0697 × flow(L/min) × ΔT(°C) = 46.0 kW | 8/12 bounded scope after simulated verification. Installed capacity overstates useful service by four racks. Lowering power can mask the mechanism and change the contracted workload; only the explicitly qualified eight-rack scope is available. |
| CX-02 — Normal cooling passes. The failure case does not. | Cooling; SI-003-4, SI-005-3 | Maximum modeled racks=floor(surviving kW / kW per rack) = 8 racks | 8/12 bounded scope after simulated verification. Eight accepted racks do not fulfill a ten-rack all-or-nothing job. Report usable workload scope separately from physically powered racks. |
| CX-03 — A nominal rating hides a hot joint. | Power; SI-010-4, SI-012-2 | I=P/V; joint heat=I²R = 312.5 W | 10/16 bounded scope after simulated verification. A small resistance can concentrate substantial heat. A nominal power rating and healthy room temperature do not close a localized integration risk. |
| CX-04 — Converter efficiency becomes a facility dependency. | Power; SI-013-2, SI-014-4 | Loss=Pout × (1/efficiency − 1) = 4.17 kW | 6/10 bounded scope after simulated verification. Efficiency assumptions propagate into electrical input and cooling loads. An apparently small spreadsheet error can block four complete service locations. |
| CX-05 — Rework yield is not first-pass capacity. | Manufacturing; SI-017-3, SI-024-3 | RTY=0.95 × 0.90 × 0.98 = 83.79 percent | 120/200 bounded scope after simulated verification. Yield definitions change promised supply. Expected units are planning estimates; they are not accepted serials or proof of stable rate production. |
| CX-06 — Unknown genealogy is not a clean cohort. | Manufacturing; SI-018-3, SI-019-3 | Held=known-affected + unresolved unknown (disjoint populations) = 140 assemblies | 100/240 bounded scope after simulated verification. The denominator matters: 58.3% of planned units remain unavailable, but only one third are confirmed in the failing cohort. Report uncertainty without hiding it. |
| CX-07 — A 29-week path has a 22-week window. | Supply; SI-025-2, SI-031-2 | Finish=current week + 20 + 2 + 4 + 3; slip=finish − target = 7 weeks | 40/80 bounded scope after simulated verification. The critical-path gap is seven weeks, not a generic red status. Partial capacity creates value only because the customer explicitly has useful smaller jobs. |
| CX-08 — Positive expected value does not waive a gate. | Supply; SI-029-2, SI-032-2 | Net EV=0.65 × $1,200,000 − $400,000 = 380000 USD | 40/80 bounded scope after simulated verification. Commercial value and technical admissibility are separate. The accepted scope remains forty; the other forty are a forecast, even after the spend decision. |
| CX-09 — A partial upgrade crosses the control boundary. | Firmware; SI-034-4, SI-047-4 | Exposure includes every host with the partial bundle, not only failures = 60 hosts | 100/160 bounded scope after simulated verification. A clean symptom is not a qualified configuration. Recovery can restore service while the causal investigation and prevention work remain unfinished. |
| CX-10 — The dashboard has a twelve-minute blind spot. | Firmware; SI-033-4, SI-036-4 | Age ratio=12 minutes / 5 minutes = 2.4 times | 24/40 bounded scope after simulated verification. A monitoring fix restores observation, not automatically hardware health. Capacity claims need fresh evidence for the actual released population. |
| CX-11 — Line rate is not delivered collective bandwidth. | Interconnect; SI-041-4, SI-046-4 | 400 Gb/s ÷ 8 × 0.80 = 40 GB/s | 16/24 bounded scope after simulated verification. A healthy speed label and corrected errors can coexist with poor workload service. Protect the qualified topology rather than counting all powered ports. |
| CX-12 — Fast steps. Slow completed work. | Interconnect; SI-042-4, SI-048-4, SI-056-4 | Goodput=100 × (60−5−2)/60 = 88.33 steps/s | 16/32 bounded scope after simulated verification. Business output is completed useful work, not the best healthy interval. A recovery improvement can be worth more than a small compute-clock gain. |
| CX-13 — More peak FLOPs will not move this roofline. | TPU; SI-049-2, SI-051-4 | min(200 TFLOP/s, 40 FLOPs/byte × 1.2 TB/s) = 48 TFLOP/s | 32/64 bounded scope after simulated verification. The bottleneck moves the decision from more theoretical compute to workload shape, data movement and integration. Installed workers are not equivalent to accepted application capacity. |
| CX-14 — A sharding fix moves the risk into the fabric. | TPU; SI-050-2, SI-052-4 | 18+6+3−22 = 5 GiB | 32/64 bounded scope after simulated verification. Solving memory capacity may create a network or goodput bottleneck. The close test must follow the dependency that the proposed fix changes. |

Each set has a defensible full-hold alternative with zero new accepted scope. Quantities from different sets have different units and must not be added as one capacity metric.
